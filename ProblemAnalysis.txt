1. Problem Analysis
1.1 ปัญหาของระบบ

ระบบมี Printer เพียง 1 เครื่อง แต่มีผู้ใช้งานหลายคนส่งงานพิมพ์เข้ามา ทำให้ต้องจัดลำดับว่า Print Job ใดควรพิมพ์ก่อน
หากจัดลำดับไม่เหมาะสม งานบางงานอาจต้องรอเป็นเวลานาน จึงต้องนำ Algorithm มาช่วยจัดลำดับ Print Job และเปรียบเทียบประสิทธิภาพของแต่ละวิธี
โปรแกรมนี้เปรียบเทียบ 2 Algorithm ได้แก่

Algorithm A: FIFO Queue
งานที่เข้ามาก่อนจะถูกพิมพ์ก่อน
Algorithm B: Shortest Job First (SJF)
งานที่มีจำนวนหน้าน้อยที่สุดจะถูกพิมพ์ก่อน
จุดประสงค์คือเปรียบเทียบว่า Algorithm ใดสามารถลด Average Waiting Time ได้ดีกว่า

1.2 Input
ข้อมูลของ Print Job ที่เข้าสู่ระบบ ได้แก่
ข้อมูล	ความหมาย
Job ID	รหัสของงานพิมพ์
User	ผู้ส่งงาน
Number of Pages	จำนวนหน้าที่ต้องพิมพ์
Submit Time	เวลาที่ส่งงาน
Priority	ระดับความสำคัญ

ตัวอย่าง
J1
User1
20 pages
Submit Time = 0
Priority = 1

รายการ Print Job ใน Queue
ลำดับการพิมพ์
Job ที่กำลังพิมพ์
Job ถัดไป
ผลการยกเลิก Job
Waiting Time ของแต่ละ Job
Average Waiting Time

ตัวอย่าง
J4 → J2 → J5 → J3 → J1

Average Waiting Time = 9.0
1.4 Constraints

ข้อจำกัดของระบบมีดังนี้
มี Printer เพียง 1 เครื่อง
Printer สามารถพิมพ์ได้ทีละ 1 Job
Job ที่ยังไม่ได้พิมพ์จะต้องอยู่ใน Queue
จำนวนหน้าต้องมากกว่า 0
FIFO จะจัดตามลำดับการเข้าคิว
SJF จะจัดตามจำนวนหน้าจากน้อยไปมาก
ถ้าจำนวนหน้าเท่ากัน จะใช้ลำดับการส่งงานเป็นตัวตัดสิน
